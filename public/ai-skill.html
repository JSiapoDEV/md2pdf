Let AI agents create, update, and share styled documents.

Install the skill, or run the md2pdf-studio CLI or its MCP server. Agents turn Markdown into an end-to-end encrypted link that opens as a styled document the reader can download as PDF, HTML or an image.

Install

The skill is a fixed text you can read before installing. It never tells an agent to fetch instructions from this site, and every command names an exact version of the CLI, so what your agent runs does not change until you decide to update.

AgentHow
Claude CodeThe plugin, which updates on its own: claude plugin marketplace add jsiapo-dev/plugins, then claude plugin install md2pdf-studio. Or only the skill: npx -y md2pdf-studio@0.1.3 skill --install
Claude Desktop, claude.aiCopy the skill, paste it in a chat and say "install this skill" (or upload md2pdf-skill.zip in Customize → Skills). There, code runs in a temporary sandbox: it needs network access to md2pdf.studio (Settings → Capabilities), and links made there cannot be updated or deleted later.
Codex, Cursor, Gemini CLIAdd to AGENTS.md (or the agent's instructions file): "To share Markdown as a private link, run npx -y md2pdf-studio@0.1.3 share <file> and give the user the full link. Before sharing, remove secrets or ask the user."
MCP clients{ "mcpServers": { "md2pdf-studio": { "command": "npx", "args": ["-y", "md2pdf-studio@0.1.3", "mcp"] } } }
Browser agentsWebMCP tools in the editor (convert-markdown, export-document, share-document, set-style). Experimental: only browsers in Chrome's WebMCP trial expose them.

The plugin brings each new version when Claude Code updates its plugins. Elsewhere, once a day the CLI and the MCP server check npm for a newer version number and say how to update: changelog shows what changed and upgrade reinstalls the skill. Nothing is installed on its own; MD2PDF_NO_UPDATE_CHECK=1 turns the check off.

FAQ

Does MD2PDF support MCP?

Yes. The npm package includes a local MCP server (npx -y md2pdf-studio@0.1.3 mcp) with four tools: share, update, delete and list links. In the browser, the editor also exposes WebMCP tools, which are still experimental in Chrome.

Do agents need an account?

No. There is no sign-up. Writes are limited per address: 10 a minute and 100 a day.

Can agents update previously-created documents?

Yes, from the same machine: npx -y md2pdf-studio@0.1.3 update <link> file.md keeps the link and replaces its content. The CLI keeps each link's edit key in ~/.config/md2pdf-studio/links.json, readable by the current user only.

Are agent-created documents encrypted?

Yes. The CLI encrypts every document with AES-256-GCM on the agent's machine before upload, and the key stays in the link's #k= part. The server never sees the key or the text, and it rejects plaintext. How links work.
